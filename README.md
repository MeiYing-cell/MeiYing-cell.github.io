# Bo Zhu · Personal homepage & blog

Public bilingual homepage: https://meiying-cell.github.io/

Chinese is the default interface language, with an English switch and light/dark themes. The homepage presents education, industry experience, research interests, downloadable resumes, and the three latest articles.

The blog lives at `/blog/`. Articles currently belong to **个人思考 / Personal Reflections**, with multiple topic tags. Category/tag filtering, individual article pages, a table of contents, reading progress, and RSS are available. The articles retain their original Chinese text when switching interface language.

This repository contains the deployable static output. GitHub Pages serves the root of the main branch; `.nojekyll` preserves the static files. The Markdown authoring source and generator are maintained in the separate source checkout. Future updates should regenerate and synchronize the output, including nested article folders and assets.

Phone and business metrics in the downloadable resumes are public with the owner's explicit approval. Unpublished research papers are not listed.
