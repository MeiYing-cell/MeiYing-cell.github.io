# Bo Zhu - Personal Homepage

Bilingual personal homepage for Bo Zhu, with career interests, research interests, industry experience, education, and downloadable resumes.

## Editing

- `profile.js`: experience, education, contact, and resume paths.
- `app.js`: English/Chinese copy and interactions.
- `styles.css`: layout, typography, color, and motion.
- `resume/`: Chinese original and English resume PDFs.

This is a static site. GitHub Pages can publish the `main` branch from the repository root. `.nojekyll` keeps the static files unchanged.

To preview locally, run `python3 -m http.server 4173` in this directory.
